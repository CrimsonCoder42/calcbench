## Notes for the lead

- New sentinels in algo/stream: ErrAlpha (ewma_stream.go), ErrVolume (streaming_vwap.go), ErrTickSize (price_tick.go).
- Shared private helpers: newWindow/clearWindow (windowed_variance.go), correlation/beta (online_covariance.go), checkTrade/vwap (streaming_vwap.go); reduce.AllFinite and reduce.NeumaierAdd are called, not re-implemented.
- No periodic recompute inside any Add (O(1) worst case); WindowedVariance/Covariance/ZScore expose Resync() O(w) for the caller. Drift is documented: absolute error scales with the data that passed through, so w ≤ 3 windows of nearly equal values can read large relative error (simulated 3e-4 at w = 2). The 1e-9 relative oracle therefore holds for w ≥ 7; w ≤ 3 is checked against 1e-9 of the series variance (stated in the test).
- WindowedZScore uses the sample std of the window INCLUDING the newest value (API choice; alternative: z against the preceding w values, lost because it would differ from NUM-STATS-028's definition of the score of a sample member).
- EWMAStream ErrOverflow and ALG-WINDOW-014's are defensive; no input found that triggers them (not tested).
- RunningStats (ALG-STREAM-004) has no Reset; D3 asks for one. Not added (released type, outside this brief); flag for a later additive change.
- Tick helpers live in algo/stream by the brief's assignment; fin/market may wrap them.
