# Bini 1996

**Citation**: Bini, "Numerical computation of polynomial zeros by means of Aberth's method", *Numerical Algorithms*, 1996, 13(2):179–200, doi:10.1007/BF02207694.

Taken: start points equispaced on circles whose radii come from the Newton polygon (upper convex hull of (i, log|aᵢ|)). Used by NUM-ALGEB-010 (polynomial_roots.go:59). Checked: oracle vs known roots; Wilkinson's polynomial; the DLMF quartic Example.

Not taken from Bini (since the fix pass of 2026-11-12, fix_algebra.md §3): the stopping rule |p(z)| < ε·s(|z|) with weights (1 + 3.8i) is removed from the code, replaced by a convergence test documented as our own and the Graillat & Ménissier-Morain 2012 noise bound (see graillat_menissier_morain_2012.md). The angle offset σ = 0.7 is kept but is our own unsourced choice, documented as such in the code (polynomial_roots.go:14–18); it is not attributed to Bini or to his pzeros code (decision for Devin in fix_algebra.md).

The one claim cited is confirmed by the abstract only ("starting approximations ... equispaced on circles of suitable radii"), which matches the Newton-polygon construction in Bini's reference code (pzeros, netlib na10; mirror jblevins.org/mirror/amiller/pzeros.f90).
