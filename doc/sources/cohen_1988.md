# Cohen 1988

**Citation**: Cohen, *Statistical Power Analysis for the Behavioral Sciences*, 2nd ed., Lawrence Erlbaum, 1988, §2.2, eq. 2.2.1, p. 20: d = (m_A − m_B)/σ.
