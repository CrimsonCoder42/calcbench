# NIST Digital Library of Mathematical Functions

**Citation**: NIST Digital Library of Mathematical Functions, §1.5(ii) "Coordinate Systems", https://dlmf.nist.gov/1.5.

**Taken**: Eq. 1.5.14 cylindrical (x = r cos φ, y = r sin φ, z), eq. 1.5.16 spherical (x = ρ sin θ cos φ, y = ρ sin θ sin φ, z = ρ cos θ), 0 ≤ φ ≤ 2π, 0 ≤ θ ≤ π; DLMF notes that mathematicians swap θ and φ.

**Used by**: NUM-LINALG-052, NUM-LINALG-053, NUM-LINALG-054, NUM-LINALG-055.
